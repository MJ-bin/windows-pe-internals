## 쓰는 말 (새로 제안, baggage "쓰는 말" 에 얹을 것)

**경로 꼴**: `함수 +0xN → 다음 함수 +0xM → … → 쓰는 함수 +0xK`. 함수 이름 뒤 `+0x..` 는 **그 함수 안에서 다음 함수를 부르는 줄** (맨 끝은 쓰는 줄). `(콜백)` = 주소를 넘겨 받은 함수가 부름 · `(IAT)` = 다른 모듈이 내보낸 함수 표로 부름 · `(주소 넘김)` = 칸 주소를 받은 함수가 씀. 약어 뒤 `+0x..` 는 약어가 가리키는 **마지막 함수** 안 줄 (예 `ⒷI +0x384` = `InitBootProcessor +0x384`). baggage 3장의 `X (호출 +0xN)` (= 직전 함수의 `+0xN` 에서 X 를 부름) 와 같은 뜻을 풀어 쓴 것이라 헷갈리지 않는다.

기존 약어 `ⒷS` · `ⒷK` · `Ⓑ2` 는 그대로 (아래 표에 풀어 씀). 새로 제안은 다섯: `ⒷI` · `ⒷM` · `ⒷX` · `ⒷP` · `ⒷL`.
